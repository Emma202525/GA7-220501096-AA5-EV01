COMANDOS DE VERSIONAMIENTO

1. Abrir una terminal en la carpeta del proyecto.

2. Inicializar Git:
git init

3. Agregar los archivos:
git add .

4. Crear el primer commit:
git commit -m "Entrega inicial GA7-220501096-AA5-EV01"

5. Crear un repositorio vacío en GitHub con el nombre:
EMMA_ALVAREZ_AA5_EV01

6. Conectar el repositorio local con GitHub:
git branch -M main
git remote add origin https://github.com/USUARIO/EMMA_ALVAREZ_AA5_EV01.git

7. Subir el proyecto:
git push -u origin main

8. Copiar la URL real del repositorio en el archivo:
repositorio.txt
